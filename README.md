# Biblioteca Municipal

Sistema informático para gestão de livros, utilizadores,
empréstimos e devoluções.

## Disciplina

Introdução a Algoritmos e Programação

## Linguagem

Java

## Funcionalidades

- Registo de livros
- Consulta do catálogo
- Pesquisa por título
- Pesquisa por autor
- Registo de utilizadores
- Empréstimos
- Devoluções
- Estatísticas

## Requisitos

- Java JDK 17 ou superior

## Como executar

1. Clonar o repositório
2. Entrar na pasta src
3. Compilar o programa
4. Executar a classe Main
